# 🛒 BariraCart — Smart Tech Shopping

A modern full-stack e-commerce web application built as part of my Full Stack Development internship.

BariraCart provides product browsing, search, cart management, checkout, order processing, and an admin dashboard for managing products and orders.

## ✨ Features

### 🛍️ Customer Side

- Browse products
- Search products
- Product categories
- Product details
- Add to cart
- Increase/decrease quantity
- Remove from cart
- Persistent cart using LocalStorage
- Checkout
- Order placement
- Order ID generation
- Responsive design

### 🔐 Admin Side

- Admin login
- Dashboard statistics
- Total orders
- Pending orders
- Recent orders
- Order management
- Order details
- Update order status
- Add products
- Edit products
- Delete products
- Stock management

BariraCart uses MySQL to manage:

- Users
- Products
- Orders
- Order Items
- Order Status

## ⚙️ How to Run

1. Clone the repository.
2. Open the project folder.
3. Run `npm install`.
4. Start Apache and MySQL in XAMPP.
5. Make sure the BariraCart MySQL database is available.
6. Run `node server.js`.
7. Open `http://localhost:3000`.
